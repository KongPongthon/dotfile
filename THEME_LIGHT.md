# ☀️ Theme Palette Reference: Rumda Light x Rainy Keyboard

A warm, non-glare, eye-friendly light aesthetic inspired by **Rumda Light** (Warm Sand / Rice Paper canvas) blended with **Rainy 75 Keyboard** color tokens (Deep Violet-Slate Ink, Lavender Purple, Slate Blue, and Muted Cyan).

---

### 🎨 Color Tokens (Light Palette)

| Token | Hex | Element Role | Visual Reference |
| :--- | :--- | :--- | :--- |
| `bg.canvas` | `#F4EFEA` | Main window background (Kitty, Hyprland canvas, Rofi window) | Rumda Warm Sand Paper Base |
| `bg.surface` | `#E8DFD7` | Card / Module surface (Waybar pills, Mako notification cards, Drawer input) | Warm Cream Parchment |
| `bg.hover` | `#D8CBC0` | Active selection, hovered modules & buttons | Warm Taupe Selection |
| `border.subtle`| `#C8B9AC` | Inactive dividers and subtle borders | Warm Muted Border |
| `fg.primary` | `#2B2538` | Primary text & code lettering | Rainy Deep Violet Ink |
| `fg.secondary` | `#534C64` | Secondary text, module labels, window titles | Rainy Modifier Shadow |
| `fg.muted` | `#8A8099` | Inactive tabs, placeholder text, dim icons | Rainy Slate Gray |
| `accent.purple_base` | `#6E64A6` | Active workspace pill, primary accent, active borders | Rainy Purple Base (Tuned) |
| `accent.purple_light`| `#8E86C6` | Active window border gradient high, focus outline | Rainy Purple Highlight |
| `accent.blue` | `#4A6D8C` | Directory path in prompt, info badges, icons | Rainy Modifier Keycap |
| `accent.cyan` | `#2D7B8C` | Clock, network status, URLs, git status | Rainy Cyan Legend (Deep) |
| `status.red` | `#B5483B` | Errors, high temperature, urgent workspaces | Rumda Terracotta Red |
| `status.orange` | `#C57434` | Warnings, high CPU/RAM usage | Rumda Warm Caramel |
| `status.green` | `#497E54` | Success, network connected | Sage Olive Green |
